# Chunking Strategy Sample

Комплексный пример построения мультимодального корпоративного RAG-пайплайна для сложных и неоднородных документов в **SmartDocs**.

## Описание сценария

Пример демонстрирует обработку реальных документов различных форматов из директории `data/`:
* **Word DOCX** (`DocumentFormat.OpenXml`): извлечение иерархии заголовков, нумерованных списков, таблиц в Markdown и растровых иллюстраций (`word/media/`).
* **Excel XLSX** (`DocumentFormat.OpenXml`): парсинг рабочих листов и авто-конвертация таблиц в Markdown со строгой структурой столбцов.
* **PDF** (`PdfPig`): посимвольная сборка строк по базовым линиям координат (`BoundingBox.Bottom`), детекция колонок, таблиц, встроенных схем и диаграмм с автоматической очисткой колонтитулов и дедефисацией.
* **Markdown**: прямое выделение секций, таблиц и блоков кода.

## Этапы пайплайна

1. **Парсинг и нормализация**: извлечение сырого текста, таблиц и изображений.
2. **Предобработка текста**: склейка разорванных переносами слов (`преобразова-\nтель` → `преобразователь`), удаление колонтитулов и фильтрация пустых страниц.
3. **Мультимодальное обогащение**: формирование текстовых описаний для архитектурных диаграмм и графиков с помощью Vision-моделей (`IImageCaptioner`).
4. **Контекстуализация**: применение Anthropic Contextual Retrieval (`ContextualChunker`) для добавления общего контекста документа к каждому фрагменту.
5. **Векторизация**: генерация плотных эмбеддингов локальной моделью `BGE-M3` (1024 измерений) через ONNX Runtime.
6. **Семантический поиск**: демонстрация многоязычного поиска (RU/EN) по таблицам, спецификациям и схемам.

## Запуск

```bash
dotnet run --project samples/ChunkingStrategy
```
