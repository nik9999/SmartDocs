# SmartDocs.Reranking

Слой переранжирования (Reranking) для RAG-стека **SmartDocs**.

## Назначение

Реализует производственный паттерн **«Retrieve broadly, rerank precisely»** (Глава 9 книги *Production-Grade RAG*):
1. Быстрый ретривер (`IRetriever`) извлекает широкий набор кандидатов (например, 20..50 фрагментов).
2. Реранкер (`IReranker`) производит точную оценку релевантности пар (запрос, документ) и пересортировывает кандидатов, оставляя `topK` наиболее точных пассажей для генерации ответа LLM.

## Ключевые компоненты

* **`IReranker`**: Базовый абстрактный контракт (`RerankAsync`).
* **`RerankingMiddleware`**: Декоратор над `IRetriever`, запрашивающий у базового ретривера `Math.Max(CandidateCount, topK)` результатов и переранжирующий их.
  * **Порог отсечения (`MinScore`)**: Отбрасывает пассажи ниже минимального балла релевантности. Если ни один кандидат не прошел порог, возвращает пустой список, позволяя модели честно ответить «Не найдено информации в документах».
* **Реализации `IReranker`**:
  * **`NoOpReranker` (`mode = "none"`)**: Сохраняет порядок кандидатов, только обрезая список до `topK`. Используется для контроля в A/B-тестах и как дефолтное поведение.
  * **`LlmRerank` (`mode = "llm"`)**: Реализация *LLM-as-a-judge* через `IChatClient` (например, Сбер **GigaChat**). Промпты на русском языке с нормализацией оценок от 0.0 до 1.0 (поддержка разделителей `.` и `,`).
  * **`CohereReranker` (`mode = "cohere"`)**: Облачный API Cohere Rerank v3.5 (требуется `COHERE_API_KEY`).
  * **`OnnxCrossEncoderReranker` (`mode = "onnx"`)**: Адаптер для локального инференса кросс-энкодера через порт `ICrossEncoderModel`.
* **`ICrossEncoderModel`**: Легковесный порт без нативных зависимостей для интеграции с локальными моделями.

## Регистрация в DI

```csharp
// Требуется предварительная регистрация IRetriever
services.AddSmartDocsReranking();
```

Конфигурируется в `appsettings.json` через секцию `SmartDocs:Reranking`:
```json
{
  "SmartDocs": {
    "Reranking": {
      "Mode": "onnx",
      "CandidateCount": 20,
      "MinScore": 0.5
    }
  }
}
```
