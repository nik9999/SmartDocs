# SmartDocs.Ingestion.Tests

Набор модульных и интеграционных тестов для модулей предобработки, SQLite-хранилища, компилятора фильтров и слоя реранкинга.

## Описание тестовых сценариев

* **Предобработка и очистка текста (`PreprocessingTests`)**:
  * Дедефисация: склейка разорванных дефисом слов на переносах строк (`преобразова-\nтель` → `преобразователь`, `частотно-\r\nрегулируемый` → `частотно-регулируемый`).
  * Фильтрация пустых страниц и служебных страниц-заглушек («Для заметок», «Лист регистрации изменений», штампы).
  * Очистка колонтитулов и номеров страниц.
  * Схлопывание точечных отточий в оглавлениях.
  * Проверка декоратора `PreprocessingChunker`.
* **Векторное хранилище SQLite (`SqliteVectorStoreTests`)**:
  * Создание таблиц и индексов.
  * Добавление и обновление векторов (`UpsertAsync`).
  * Ранжирование по аппаратному SIMD-косинусу (`CosineKernel`).
  * Удаление векторов и обработка конфликтов ключей.
* **Гибридный ретривер SQLite (`SqliteHybridRetrieverTests`)**:
  * Создание виртуальной таблицы FTS5 и триггеров синхронизации.
  * Проверка слияния рангов Reciprocal Rank Fusion (RRF $K=60$) за один SQL round-trip.
  * Префиксный поиск русских морфологических форм (`"преобразователь"*` находит форму «преобразователями»).
  * Безопасный fallback на чисто векторный поиск при запросах без текстовых токенов.
  * Регистрация в DI (`AddSmartDocsSqliteHybridRetriever`).
* **Компилятор фильтров SQLite (`SqliteFilterCompilerTests`)**:
  * Трансляция выражений `MetadataFilter` в SQL `json_extract`.
  * Проверка операторов сравнения, строковых методов (`Contains`, `StartsWith`), операторов `IN` и null-проверок.
  * Инлайнинг лямбда-выражений при композиции фильтров через `.And()` и `.Or()`.
  * Безопасный fallback при нестандартных C#-выражениях.
  * End-to-end проверка database pre-filtering в `SqliteVectorStore` и `SqliteHybridRetriever`.
* **Слой реранкинга (`RerankingTests`)**:
  * Обрезка списка без изменения порядка в `NoOpReranker`.
  * Пересортировка кандидатов моделью кросс-энкодера `OnnxCrossEncoderReranker`.
  * Оценка релевантности в `LlmRerank` на русском языке с нормализацией разделителей (`.` и `,`).
  * Расширение пула кандидатов (`CandidateCount`) и отсечение слабых пассажей по порогу `MinScore` в `RerankingMiddleware`.
  * Проверка регистрации и декорирования `IRetriever` через DI (`AddSmartDocsReranking`).

## Запуск тестов

```bash
dotnet test tests/SmartDocs.Ingestion.Tests/SmartDocs.Ingestion.Tests.csproj
```
